# Kono'S releases

Downloads for Kono'S, the self-hosted assistant. Start at https://thekonos.com/download/

This repository holds release files only. It contains no source code.

## Install (macOS)

Requirements: a Mac with Apple silicon (M1 or later), with Claude Code or Codex CLI signed in on that Mac.

1. Download `KonoS-<version>.dmg` from the latest release.
2. Optional: check the file with `shasum -a 256 KonoS-<version>.dmg` and compare it to the `.sha256` file in the same release.
3. Open the DMG and drag Kono'S to Applications.
4. Open Kono'S. It opens your browser at http://127.0.0.1:8080/
5. Create the owner account with the setup code Kono'S shows.

This is an alpha: many features are experimental, and the known issues are listed in each release's notes.
